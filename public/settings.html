Household password

Everyone who knows this password can view and edit the calendar. Changing it signs out every other device.

Family

The people on this calendar. Each has a color and an optional emoji. (Everyone shares the one household password — this is just how they're labeled on events.)

Categories

Shared event types — assign calendars or events to these to color them as a group.

Chores & points

You give each chore a point value on the To-Do tab — points are just how you set what a chore is worth relative to the others. The family never sees them: everyone sees what they've earned in money.

Kinboard tracks earnings every time a chore is completed — including repeating ones, every time round. Until you set a value above, nothing is shown to the family.

Sharing

Give grandparents, sitters, or a co-parent a view-only link, or subscribe this calendar into Google/Apple Calendar so it shows up on everyone's phone. Anyone with a link can view — but not edit. Turn it off anytime.

Any event — yours or from an imported calendar — whose title contains one of these words is shared to the links below. Everything else stays private. Case-insensitive.

Subscribe to calendar

Imported iCal feeds — school, sports, work. Assign each to a person or category.

Ingest a calendar

One-time migration from Google, Apple, Outlook, or any iCal link — copies events in as native, fully-editable events on this calendar. Unlike a feed above, it does not stay live-synced.
